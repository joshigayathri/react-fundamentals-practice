# React Fundamentals Practice

A beginner-friendly React.js practice repository built using **React.js and Vite**.

This repository contains hands-on exercises and mini-projects to learn React fundamentals and modern JavaScript concepts.

## Technologies Used

- React.js
- JavaScript (ES6+)
- Vite
- HTML
- CSS

## Concepts Practiced

- JSX
- Functional Components
- JavaScript Object Destructuring
- Array Destructuring
- Arrow Functions
- Array Methods (`map()`)
- Import and Export
- Rendering Lists in React
- React Keys

## Mini Projects

- Calculator
- Student Profile
- Student List

## How to Run the Project

1. Clone this repository:

   `git clone https://github.com/joshigayathri/react-fundamentals-practice.git`

2. Open the project folder:

   `cd react-fundamentals-practice`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

This repository documents my learning journey in React.js through practical exercises and beginner-level projects.
